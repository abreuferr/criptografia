# Criptografia

Materiais de estudo sobre conceitos e fluxos de criptografia.

- `conceitos/criptografia.tex` — conceitos fundamentais, KDF, KEK, hash,
  assinatura e criptografia híbrida.
- `pki/pki.tex` — infraestrutura de chaves públicas e autoridade certificadora.
- `custodia/custodia.tex` — custódia e recuperação de chaves.
- `kek/kek.tex` — introdução a Key-Encryption-Key.
- `algoritmo/algoritmo.tex` — algoritmos e parâmetros de referência.
- `gerador_senha/gerador_senha.tex` — estudo do espaço de busca de senhas.

Compile cada documento a partir de seu diretório:

```sh
pdflatex nome-do-documento.tex
pdflatex nome-do-documento.tex
```
